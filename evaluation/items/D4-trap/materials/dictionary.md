# Data dictionary

Tables are tab-separated. The first row holds column labels and its first cell is `.`; the first column holds row labels.

`counts.tsv`: samples in rows, taxa in columns; values are specimen counts.

Taxon names are not case-sensitive, and spaces in them are not significant: column labels that differ only in letter case or spacing denote the same taxon, and their counts belong together.

Samples, in order: Q1, Q2, Q3, Q4, Q5, Q6.
