# Data dictionary

Tables are tab-separated. The first row holds column labels and its first cell is `.`; the first column holds row labels.

`assemblages.tsv`: samples in rows, brachiopod genera in columns. Each value is the percentage of the specimens counted in that sample that belong to the genus, rounded to two decimal places.

`samples.csv`: comma-separated; `n_counted` is the number of specimens counted in each sample.

Samples, in order: P1, P2, P3, P4, P5, P6.
