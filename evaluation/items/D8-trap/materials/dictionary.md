# Data dictionary

Tables are tab-separated. The first row holds column labels and its first cell is `.`; the first column holds row labels.

`counts.tsv`: samples in rows, brachiopod genera in columns; values are specimen counts. A `.` means the genus was not assessed in that sample: Lingula was not identified separately in samples processed before 1998 (B1–B3). Comparisons between samples must use only taxa assessed in every sample.

Samples, in order: B1, B2, B3, B4, B5, B6.
