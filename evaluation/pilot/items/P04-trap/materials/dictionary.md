# Benthic foraminifera, two campaigns

`counts.tsv` is a classic PAST table, one row per core, one column per taxon. `cores.csv` gives each core's campaign.

Taxa T09–T11 occur only in the 63–150 µm fraction and taxa T01–T08 only in the >150 µm fraction. The >150 µm fraction was picked completely in both campaigns; the 63–150 µm fraction was picked only in 2021. Cells for fractions that were not picked are entered as '.'.
