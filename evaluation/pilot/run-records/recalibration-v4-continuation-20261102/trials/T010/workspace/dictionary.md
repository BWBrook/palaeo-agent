# Storm Bay benthic foraminifera

- `counts.tsv`: tab-separated; one row per laboratory number, one column per taxon.
- `register.csv`: the sample register: `lab_number`, the `core_id` it came from, `split` (letter of the residue split processed under that number, blank if unsplit) and `batch`.
- `cores.csv`: one row per core: `zone`, `site_spacing_km` (distance to the nearest other site), `water_depth_m`. Each core was taken at its own site.
- `lab_log.csv`: processing log by laboratory number.
