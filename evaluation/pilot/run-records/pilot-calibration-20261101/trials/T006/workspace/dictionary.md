# Planktonic foraminifera, margin transect

`assemblage.tsv` is a classic PAST table with one row per sample and one column per species (underscores replace spaces).

Values in `assemblage.tsv` are percentages of the specimens picked from each sample; the number picked is in `picking.csv` (`n_picked`).

Picking targeted 200 to 1000 specimens from the >150 µm fraction.
