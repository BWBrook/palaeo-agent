# São Roque shelf foraminifera, two campaigns

- `counts.tsv`: tab-separated; one row per sample, one column per taxon.
- `samples.csv`: `sample_id`, `campaign`, `value_type` (how the row's values are expressed), `n_counted` (specimens identified in the sample), `source`.
- `lab_log.csv`: processing log for samples handled in this study's laboratory.
