# Pelotas slope foraminifera

- `counts.tsv`: tab-separated; one row per counted sample (`sample`), one column per taxon; specimen counts.
- `stations.csv`: the station list compiled from both cruise legs: `station_id` as written in that leg's station log, `zone` (A: upper slope, B: lower slope, assigned from sedimentology), `water_depth_m`, `leg`. Stations were placed at random within zones. Some stations yielded no sample.
- `lab_log.csv`: processing log (`sample_id`, `processed`, `analyst`, `remark`).
