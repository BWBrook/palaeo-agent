# Kerguelen transect foraminifera

- `counts.tsv`: tab-separated export from the laboratory database. The first column names the taxon; each further column is one sample (KC01–KC23, ordered along the transect). Cells are numbers of specimens picked from the >150 µm fraction.
- `lab_log.csv`: one row per sample from the processing log: `sample_id`, `processed` (date), `analyst` (initials) and `remark` (free text written at the bench).
