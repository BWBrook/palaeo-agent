# Tasman slope core-top foraminifera

- `counts.tsv`: tab-separated; taxa as rows, cores as columns; specimen counts.
- `cores.csv`: `core_id`, `campaign`, position.
- `campaigns.csv`: per campaign, `vessel`, `sieve_mesh_um` (mesh used to wash the sediment) and `picking`.
- `taxa.csv`: `adult_test_size` for each taxon, from the regional atlas.
