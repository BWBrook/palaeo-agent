# Core MD-17 foraminifera

- `counts.tsv`: tab-separated; one row per sample, one column per taxon; specimen counts.
- `samples.csv`: `sample_id`, `depth_cm` (below core top).
- `dates.csv`: radiocarbon dates with calibrated ages: `lab_code`, `depth_cm`, `age_cal_bp`, `status` and `comment` from the dating report.
