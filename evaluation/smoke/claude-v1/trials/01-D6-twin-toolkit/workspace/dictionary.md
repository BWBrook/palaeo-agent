# Data dictionary

Tables are tab-separated. The first row holds column labels and its first cell is `.`; the first column holds row labels.

`counts.tsv`: specimen counts of brachiopod genera in samples.

Samples, in order: M1, M2, M3, M4, M5, M6, from successive beds of one section.

Taxa recorded: Dalmanella, Sowerbyella, Howellites, Platystrophia, Orthis, Strophomena, Rafinesquina, Leptaena.
