# Data dictionary

Tables are tab-separated. The first row holds column labels and its first cell is `.`; the first column holds row labels.

`counts.tsv`: samples in rows (labelled by sample ID), brachiopod genera in columns; values are specimen counts.

`samples.csv`: comma-separated, one row per sample, with its `sample_id`, `facies` (reef or lagoon) and stratigraphic `height_m`.
