# Independent references and PAST 5.4 validation — 31 October 2026

The declared community and RMA calculations agree with native PAST 5.4
exports within their exported precision: 90 distinct off-diagonal similarities,
20 continuous diversity indices and 20 counts, 18 RMA point estimates,
217 fitted values, 27 non-null eigenvalues and 120 scaled coordinates.
The audit count is 1,059 cells across thirteen captures, including duplicated
entries and source-data identity checks. The Python suite passed 138 tests
at e04b592. No product numerical methods changed in that tranche.

This is validation of two known development datasets and named settings.
It does not establish general PAST parity, coverage of the current PAST
example corpus, inferential validity or a reduction in agents' error rates.

diagonals, repeated estimates and **434 original X/Y values** are included.

checked exactly. Rounded, rather than truncated,
export formatting is the declared assumption; the captures satisfy the
tighter rounded intervals. Our internal `1e-10` is not an export tolerance.

## Findings that affect workflow design

**Displayed settings can disagree with displayed results.** In the diversity
module, changing “Unbiased versions” from ON to OFF did not update the table
until Recompute was pressed. The first
[stale capture](../references/past/captures/c2-before-recompute/) retains
corrected Simpson and Shannon estimates alongside the unchecked option.
Their corrections independently identified the stale output. The comparator
rejects all 20 affected cells. The accepted
[C2 capture](../references/past/captures/c2-diversity/) was copied after
Recompute, with unbiased versions, ACE-for-S and log2 OFF and CI type None.
This is a concrete example of the state ambiguity our explicit API avoids;
it is not an agent-efficacy trial.

**PAST retains complete pairs separately by locality.** Selecting all six
Dielasma columns together exported 103 rows with three four-column residual
blocks. Their nonempty masks and original X/Y sequences verify counts
**103, 79 and 35**. The fitted values match each full-locality RMA, rather
than deletion across all six columns to 35 shared rows. Residual values,
standard errors, confidence intervals, hypothesis tests and permutation
outputs are preserved but not validated here. PAST computes bootstrap
intervals with N=1999; no reproducible seed was available in these captures.

**PCoA conventions need explicit translation.** All three cases—raw
Bray–Curtis, relative-abundance Bray–Curtis and binary Jaccard—exported all
ten eigenvalues, despite the manual's more limited description. Each has
eight positive axes, one structural null and one negative axis. The nine
non-null eigenvalues agree, including the negative value. Both null values
must lie within `128 * epsilon * n * max(abs(eigenvalues))`; their actual
values are reported, and they are excluded from the numerical cell count.
The captured PAST calculations match classical PCoA with distance `d = 1 - s`
for both Bray–Curtis and Jaccard similarities, exponent `c = 2`, and
double centring `-0.5 * J * d² * J`. This is empirical agreement for the
captured cases, rather than an inspection of PAST's internal implementation.

“Eigenvalue scale” defaults OFF in a new PCoA dialog. We explicitly enabled
it before copying the accepted coordinates. The first four axes agree after
sign flips only; no rescaling, rotation or fitted correction was used. Their
adjacent eigengaps support individual axis identification. Higher exported
score columns are retained but not validated. An additional unscaled raw
Bray–Curtis export agrees with unit eigenvectors as a diagnostic.

PAST's **Percent** uses `100 * eigenvalue / sum(abs(eigenvalues))` in these
cases. Absolute inertia matches all nine non-null percentages in each case;
positive and signed denominators each fail all nine. Palaeo-Agent reports
positive-axis inertia fractions. This explained convention difference is
recorded separately and excluded from the product-match count. Relative
abundance was produced in PAST with Row percentage; multiplying every
sample's proportions by 100 leaves Bray–Curtis unchanged.

## Independent R/vegan execution

The [separate check](validation-independent-check.md) regenerated the
committed reference with the existing renv library: R 4.6.1, vegan 2.7-6,
permute 0.9-10 and jsonlite 2.0.0. Excluding only the generation timestamp,
**1,010 numeric values and all other fields were reproduced exactly**.
The largest Python–vegan difference was `2.44249e-15`. The
[regenerated reference, session and comparison evidence](../references/independent/2026-10-31/)
are archived. No packages were installed and no global R settings changed.
This supplies independently authored algorithm and parser checks; both
linear-algebra paths ultimately use LAPACK.

## Reproduce and extend

```sh
uv run python scripts/compare_past_captures.py --output /tmp/past-comparison.json
uv run pytest -q
```

The tests reject altered numeric values, changed labels, missing regression
fields, partial locality pairs, the stale diversity export, a non-null value
substituted for the structural null, and coordinate rescaling. They allow
the arbitrary sign of an eigenaxis. Further checks reject missing manifests,
wrong settings, changed artifact hashes and overly permissive rounding at
powers of ten.

E0 scripting feasibility was not needed for native Copy acquisition and
remains untested. The useful next tranche is held-out validation with small
analytical and adversarial datasets, followed by the already proposed
development smoke of the agent-evaluation protocol. Those checks should
test whether explicit inputs, diagnostics and evidence bundles reduce
mistakes and make independent checking easier. No agent trial campaign or
new inferential method was added in this tranche.
