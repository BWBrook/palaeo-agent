# Third-party reference material

This repository is private during development. Barry supplied
`docs/past5manual.pdf` and `benchmarks/past/casefiles.ZIP` and explicitly requested
archiving the 2001 case-study vignettes for workflow cross-checking. These files,
extracted data and captured pages retain their original authorship and rights.
No open redistribution licence is asserted for them.

- PAST 5.4 reference manual: Øyvind Hammer, Natural History Museum, University
  of Oslo. [Official download page](https://www.nhm.uio.no/english/research/resources/past/).
- 2001 case studies, data and images: original PAST project, Hammer, Harper and
  Ryan, and the sources credited within each vignette.
  [Original index](https://palaeo-electronica.org/2001_1/past/pastprog/doc1.html).
- [PAST software terms](https://www.nhm.uio.no/english/research/resources/past/terms-reference-etc.html)
  describe software redistribution restrictions. They do not establish a
  separate open licence for every example dataset or illustration.

The capture manifests record source URLs and checksums. Original HTML is
preserved separately from copies whose links were rewritten for offline use.
No PAST executable is included, and no current PAST application has been run
for this project's numerical comparisons.

Before making this repository public, establish the rights for each bundled
reference or replace it with a permitted acquisition mechanism. A future
licence for Palaeo-Agent's own code must not be presented as relicensing this
material. Private development and public release are separate decisions.
